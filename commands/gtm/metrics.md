Run the GTM Metrics exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 5: Metrics).

1. Understand the product and its core value proposition (read project context)
2. Define the North Star Metric — the one number that captures customer value
3. Build a KPI tree branching from the north star into acquisition, activation, revenue, retention, referral
4. Fill out the KPI Framework table with specific metrics, targets, tools, and review frequency
5. Identify 2-3 anti-metrics (vanity metrics to explicitly NOT optimize for)
6. Create a measurement plan: event names, tracking tools, dashboard locations, alert thresholds

Ask the user what analytics tools they already use (GA4, Mixpanel, Amplitude, Stripe, etc.) and what they currently track.
