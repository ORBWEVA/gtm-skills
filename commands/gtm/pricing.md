Run the GTM Pricing exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 3: Pricing).

1. Understand the product — read codebase, landing page, Stripe config if available
2. Walk through the pricing model options table — discuss which models fit
3. Run the Value-Based Pricing Analysis — ask the user for customer data points they know
4. Do competitive price benchmarking — ask about or research competitors
5. Recommend a tier structure (max 3 tiers) with feature differentiation
6. Specify the anchor tier (the one you want most people to pick)
7. Address free tier / trial strategy

Never recommend "just charge $X." Always show the reasoning chain: value delivered → willingness to pay → competitive context → recommendation.
