Run the GTM Channels exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 2: Channels).

1. Review the project's ICP (from positioning, if available) or ask who the target customer is
2. List all candidate channels from the channel category table
3. Score each channel using the Channel-Market Fit Matrix — ask the user for input on ICP presence and CAC estimates
4. Select 2-3 primary channels with clear rationale
5. For each selected channel, create a 30-day action plan with specific, actionable steps
6. Include content/creative needs, tools required, expected costs, and leading indicators

Bias toward channels the user can start TODAY with minimal budget. Pre-PMF = scrappy.
