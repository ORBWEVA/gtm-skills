Run the GTM Outreach exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 6: Outreach).

1. Review the project's ICP (from positioning, if available) or ask who the target customer is
2. Identify 3-5 sales triggers relevant to the ICP using the trigger categories
3. Determine the right messaging tier (ATL for VP/C-Suite vs BTL for Manager/IC)
4. Write a 3-touch email sequence using the SPARK framework — personalized to the ICP
5. Write a LinkedIn connection + follow-up sequence (2 messages)
6. Score each message using the Personalization Hierarchy (must be level 3+ for B2B)
7. Provide subject line variants and a send cadence timeline

Push for specificity. "Great company" is not personalization. Reference a trigger, a metric, or a decision they made.
