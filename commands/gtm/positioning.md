Run the GTM Positioning exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 1: Positioning).

1. If the user hasn't specified a product, ask what they're positioning
2. Research the project — read codebase, README, landing page, any existing docs
3. Walk through the ICP Profile template — ask clarifying questions if needed
4. Build a Value Proposition Canvas mapping customer jobs/pains/gains to product features
5. Write a Positioning Statement using the template
6. Create a Competitive Positioning Map — ask the user about competitors if not obvious
7. Deliver all four artifacts in a clean, structured format

Push the user to be specific. "Everyone" is not an ICP. "Better" is not a differentiator.
