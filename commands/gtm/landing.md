Run the GTM Landing Page exercise from `~/.claude/skills/gtm-launch/SKILL.md` (Stage 7: Landing Page CRO).

1. Read the landing page — URL, local file, or codebase (ask if not specified)
2. Score the page across all 7 CRO dimensions (value prop clarity, headline, CTA, visual hierarchy, trust signals, objection handling, friction)
3. For each dimension scoring below 8/10, provide a specific fix with before/after copy
4. Build an Objection/Counter-Objection table for the product
5. Identify the #1 quick win (highest impact, lowest effort)
6. Suggest 2-3 A/B test hypotheses with expected impact
7. If positioning data exists (from /gtm:positioning), validate that the page reflects it

Judge the page as a first-time visitor with 8 seconds of attention. If the value prop isn't clear in 8 seconds, say so.
